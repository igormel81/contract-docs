# Каталог развёртывания

Здесь два несвязанных набора файлов. Не смешивайте их.

| Путь | Для чего |
|---|---|
| `onprem/` | Установка в организации. Это то, что описывает [руководство](../references/local-deployment.md): unit с `EnvironmentFile`, пример параметров со всеми исполнителями, пример nginx и проверка песочницы `preflight.mjs` |
| `contract-docs.service` | Unit действующего публичного пилота `igoruan.ru`: параметры заданы прямо в unit-файле, добавлены `InaccessiblePaths` соседних сервисов и более жёсткие лимиты этого VPS. Для чужой установки не подходит |
| `route.py` | Публичный маршрут Caddy того же VPS. Проверяет кандидат конфигурации, делает закрытую резервную копию и применяет её сигналом SIGUSR1. Не запускать повторно без осмотра |

Установочного скрипта здесь больше нет: `install.sh` был привязан к каталогу релиза от 3 сентября 2026 и к unit-файлу пилота, то есть предлагал второй, неверный путь установки. Порядок первой установки — раздел 4 руководства.
