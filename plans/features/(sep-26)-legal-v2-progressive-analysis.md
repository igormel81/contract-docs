# Legal v2 и прогрессивный анализ

Status: in progress
Owner: Codex coordinator
Surface: правила, нормативные пакеты, анализ, API, интерфейс, тесты
Updated: 2026-09-08. Baseline release: `859271e` / 0.3.3; current candidate is uncommitted.

## Outcome

Сервис сначала квалифицирует обязательства, затем выдаёт ранний проверяемый результат и дополняет его тематическими юридическими проверками. Каждый анализ остаётся связан с неизменяемой редакцией правил и нормативных пакетов. Позиционирование до юридического подтверждения корпуса: «выявляет договорные риски и вопросы для правовой проверки».

## Global constraints

- `verified` присваивает только назначенный юрист после сверки с официальной действующей редакцией.
- Модель не создаёт URL, названия актов или нормы вне закреплённого снимка.
- Юридический вывод отделён от коммерческого риска и содержит один из типов: `mandatory_violation`, `invalidity_or_unenforceability`, `dispositive_unfavorable`, `missing_required_term`, `facts_or_documents_required`, `not_applicable`.
- Старые результаты и снимки не мигрируют и не переписываются.
- Частичный результат только дополняется; уже опубликованные элементы имеют стабильные ID и явный статус проверки.
- Новая инфраструктура пакетов по умолчанию не делает справочный корпус подтверждённым.

4. Добавить UI прогресса и административный экран нормативной базы.

6. Обновить спецификацию, README и changelog фактическими результатами; неподтверждённые элементы оставить явно незавершёнными.

## Acceptance

- Анализ содержит квалификацию каждого существенного обязательства до правовых выводов.
- Каждое замечание различает юридический тип и коммерческую критичность.
- `PD-01`, `IP-01`, `LIC-01`, `LOC-01` могут ссылаться на применимые нормы из активных модулей, но не обязаны создавать правовой вывод без покрытия.
- Ветка 44-ФЗ/223-ФЗ активируется только при соответствующей квалификации закупки.
- API пакетов требует доверенную Ed25519-подпись, точный digest, отдельного согласующего и неизменяемые записи.
- Новый анализ закрепляет набор активных модулей; старый остаётся воспроизводимым.
- Пользователь видит квалификацию и первые риски до окончания тематических проверок и ревью.
- Частичный результат не маркируется как окончательный и не исчезает при дополнении.
- «Текст для менеджера» всегда включает все замечания выбранного результата без лимита и без заглушки «смотрите в приложении»; копирование, TXT, почта и системный Share используют один и тот же полный текст.
- Есть обезличенная выборка с применимой нормой, типом нормы, ожидаемым риском, рекомендацией и случаями без замечания.
- Никакой результат не позиционируется как полноценная проверка законодательства, пока все нужные модули не подтверждены юристом.
